# 💰 FinanzasPersonales - Aplicación de Manejo de Presupuestos

## 🚀 Características Clave del Proyecto

* **Tablero Visual en Calendario**: Visualización intuitiva de las transacciones mensuales distribuidas directamente sobre una interfaz de calendario interactivo.
* **Control Completo (CRUD)**: Gestión total de múltiples entidades financieras mediante **Dapper**.
* **Exportación de Datos**: Módulo integrado para exportar el historial de transacciones a reportes de **Excel**.
* **Autenticación Propia**: Sistema de gestión de usuarios integrado con tablas personalizadas dentro de la base de datos de la aplicación.

---

## Tecnologías y conceptos utilizados

* **Framework**: ASP.NET Core MVC
* **Acceso a Datos**: Dapper para mapeo rápido y ejecución de procedimientos almacenados.
* **Base de Datos**: SQL Server.
